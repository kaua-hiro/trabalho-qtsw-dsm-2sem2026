# Cálculo do IR (Ano-base 2026) – QTSW / Grupo 2

- `src/main/java/br/fatec/qtsw/CalculadoraIR.java` – implementação (blocos numerados à esquerda, conforme o GFC)
- `src/test/java/br/fatec/qtsw/CalculadoraIRTest.java` – testes de unidade JUnit 5 (classes de equivalência, caminhos do GFC e valores limite)

Executar: `mvn test` (Java 17+). No IntelliJ/Eclipse/VS Code, basta abrir a pasta como projeto Maven e rodar a classe de teste.
